# Кофеин

Маленькое нативное macOS-приложение, которое запрещает автоматический сон, чтобы сон Mac не прерывал подключение к публичному Wi-Fi.

Открывается из Dock или через значок чашки в строке меню. При первом запуске сразу включает режим без таймера. Кнопка включает и выключает защиту от сна; последнее состояние и настройки запоминаются. Закрытие окна оставляет приложение работать. «Выйти» или ⌘Q отключает защиту и завершает приложение.

Возможности:

- Работа без таймера или на 30 минут, час, два часа. Смена длительности запускает таймер заново.
- Экран может гаснуть по обычным настройкам macOS. «Не гасить экран» включает дополнительную защиту экрана.
- Необязательный автозапуск через системный механизм macOS. По умолчанию выключен. При запуске после входа окно не открывается.
- Иконка в Dock и строке меню, спокойный монохромный интерфейс со светлой и тёмной темой.
- Нативный Liquid Glass на macOS 26+: прозрачная стеклянная поверхность окна и интерактивные элементы. На macOS 13–15 используется стандартный полупрозрачный материал.
- Контрастное состояние работы: заполненный значок чашки с галочкой и плашка «Работает». На основном экране только чашка, время и управление; пояснения открываются через ⓘ.
- Чашка — кнопка: каждый клик добавляет 30 минут к текущему таймеру. Она подпрыгивает, показывает «+30 мин», а кольцо вокруг неё показывает оставшуюся долю времени. Учитывается настройка уменьшения движения macOS. В меню есть компактная кнопка чашки «+30».
- Первая чашка из выключенного режима или режима без таймера запускает 30 минут. Следующие продлевают сессию; нажатие на готовую длительность или ∞ выбирает новый режим.
- Компактное меню, отдельное от полного окна: высота ограничена доступным экраном; при необходимости содержимое прокручивается.

Оставьте крышку ноутбука открытой. Приложение не отменяет ручной сон, выключение и ограничения самой Wi-Fi-сети: повторную авторизацию, таймауты сессии или потерю сигнала. Режим удерживает Mac бодрствующим и расходует заряд.

## Установка

Скопировать `build/Caffeinate.app` в `~/Applications` и открыть. Системные настройки электропитания и Wi-Fi не меняются. Для удаления завершить приложение, выключить его автозапуск, если он был включён, и удалить `.app`.

## Сборка

Нужны Xcode Command Line Tools и macOS 13+. Зависимостей нет.

```sh
./Scripts/build.sh
./Scripts/test.sh
```

Сборка universal: Apple Silicon и Intel. `build.sh` подписывает Developer ID из настроенного на этом Mac сертификата. Полный выпуск, включая тесты, подпись, нотариальное заверение и прикрепление билета:

```sh
./Scripts/release.sh
```

Профиль нотариального заверения: `keys-cli-notary`, можно переопределить через `NOTARY_KEYCHAIN_PROFILE`.

## Реализация и проверка

SwiftUI + AppKit, без сети и фоновых серверов. Управляет только своим процессом `/usr/bin/caffeinate -i -s -w <PID приложения>`. Параметр `-i` запрещает автоматический сон и на батарее; `-s` дополнительно запрещает системный сон при питании от сети. `-d` удерживает экран, `-t` ограничивает время. `-w` освобождает запрет сна даже после аварийного завершения приложения.

Интеграционные проверки читают настоящие power assertions macOS через `pmset -g assertions`: запуск, разрешённый сон экрана, смена настроек, выключение, истечение таймера и очистка после аварийного завершения владельца.

Отдельно проверяется кофейный таймер: добавление к существующему времени без сброса прошедших минут, произвольная длительность, переход из режима без таймера, истечение и восстановление длительности после перезапуска. Настройки тестов изолированы от пользовательских.
